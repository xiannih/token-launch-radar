How the value is worked out

Implied value = TVL × category multiple × size dampener × growth × age. TVL is the snapshot's own figure, sublinear: a dollar of TVL counts less at $2B than at $50M. Growth is the 7-day TVL change, dampened and clamped. Age is time since first tracked — older is more credible. Protocols that already record a token are excluded outright — no penalty can place a $100B token protocol honestly below a $5M pre-token one on a value-ordered board. Eligible means: no token recorded, not a wrapped, staked or bridged product, not an exchange, not a versioned copy. A protocol here records no token — that is the snapshot's record, not proof it has none. The implied value is this radar's claim, not a prediction of a launch date or price.
